# 팀 커밋은 [이름]부터

팀 저장소에 커밋할 때 메시지는 `[이름] 무엇을 왜` 형식으로 시작한다.

**왜:** 여러 명이 함께 쓰면 "누가 한 작업인지"가 로그에서 즉시 보여야 한다.
정본 규칙: `team_memory/shared/commit_rules.md`.

**어떻게 적용:**
- 커밋 도와줄 때 `[이름]` 접두사를 먼저 확인하고, 없으면 되묻는다.
- 팀 규칙이므로 개인 취향보다 우선(score 30).
