# shared/ 는 합의 후에만

`team_memory/shared/` 의 팀 공통 규칙은 한 사람이 조용히 바꾸지 않는다.
주간 회고에서 팀이 합의한 뒤에만 수정한다.

**왜:** 공통 규칙을 몰래 바꾸면 나머지 팀원이 옛 규칙으로 계속 일한다.
"모두에게 적용되는 것"일수록 바꾸는 문턱을 높인다 — 이것이 거버넌스.

**어떻게 적용:**
- `shared/` 수정 요청이 오면 "회고에서 합의된 사항인가요?"를 먼저 확인.
- 개인 예외는 `<이름>/notes.md` 에, 공통 변경은 합의 후 `shared/` 에.
