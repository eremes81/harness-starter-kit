# 공유 규칙 · 작업 흐름

> `shared/` = 팀 전원 공통. 필요할 때만 읽는다(항상 로드하지 않는다).

## 문서 승격 흐름

```
초안(개인 작업) → 팀 검토 → 합의 → shared/ 또는 team_memory/atoms 로 승격
```

- 개인이 발견한 좋은 규칙은 먼저 자기 `memory/` 나 `<이름>/notes.md` 에 둔다.
- 여러 명에게 반복 적용될 가치가 확인되면, 회고에서 **팀 공유로 승격**한다.

## 회고 → 규칙 승격 (팀 버전)

- 주간 회고에서 "이건 나만의 문제가 아니다" 싶은 교훈은 `team_memory/atoms/` 로 올린다.
- 팀 atom 은 개인 atom 보다 `score` 를 조금 높여, 충돌 시 팀 규칙이 먼저 떠오르게 한다.
