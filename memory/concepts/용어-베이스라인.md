# 베이스라인 (baseline)

**정의**: 어떤 개선(AI 도입 포함)의 효과를 말하기 전에, **도입 전 상태를 같은 단위로 잰 기준값**.

**왜:** "3~5배 빨라졌다"는 말은 도입 전 시간을 잰 적이 없으면 근거가 없다.
비교 대상이 없는 절감·효과 주장은 회의에서 무너진다.

**어떻게 적용:**
- 효과·절감·개선을 말하는 문서를 만들 때, 먼저 "도입 전 값이 있나?"부터 확인한다.
- 없으면 지어내지 말고 "베이스라인 없음 — 이번 주기부터 측정"이라고 쓴다.
