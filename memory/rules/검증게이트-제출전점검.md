# 제출 전 3중 검증 게이트

AI가 만든 요약·수치·인용·분류를 **결정·보고서·외부 제출에 반영하기 직전**,
아래 세 관문을 통과시킨다. (책 5장 "검증 게이트"의 실물)

1. **자기 검증** — "이 안에 원본에 없는 수치·인용·날짜·고유명사가 있나?" AI가 스스로 표시.
2. **결정론적 대조** — 숫자·ID·인용은 눈으로 원본과 1:1 대조(또는 검색으로 확인). 기억이 아니라 원본.
3. **사람 게이트** — 최종 반영은 사람이 승인. 외부로 나가는 것일수록 이 관문을 낮추지 않는다.

**왜:** AI는 그럴듯하지만 틀린 값을 자연스럽게 섞는다. "그럴듯함"과 "맞음"은 다르다.
게이트가 터져도 작업을 막지는 않되, **반영 전에 반드시 통과**시킨다.

**어떻게 적용:**
- "이거 보고서에 넣자 / 제출하자 / 확정하자"가 나오면 위 3관문을 먼저 언급하고 점검.
- 지어낸 값이 의심되면 "이 숫자의 출처는?"을 되묻는다.
