# 보고서·문서는 목차부터

문서를 부탁할 때 곧바로 본문을 쓰지 말고, **목차(섹션 구조)를 먼저 제안**받아
합의한 뒤 본문을 채운다.

**왜:** 본문부터 쓰면 방향이 어긋났을 때 통째로 다시 써야 한다. 구조를 먼저
맞추면 수정 비용이 작고, 빠진 항목(리스크·일정·비용 등)을 초반에 잡는다.

**어떻게 적용:**
- "보고서 써줘"가 아니라 "이 주제로 목차 3안 뽑아줘 → 고른 뒤 본문"으로 나눈다.
- 목차에는 결론·근거·리스크·다음 액션이 들어갔는지 점검한다.
