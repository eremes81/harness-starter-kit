# 주간 회고 = 금요일 오후 고정

매주 금요일 오후, 한 주의 일·결정·배운 점을 `retro/weekly/` 에 한 장으로 남긴다.

**왜:** 회고를 "시간 날 때"로 두면 영원히 안 한다. 고정 슬롯이 있어야 루프가 돈다.
회고에서 반복되는 교훈은 `memory/` 의 규칙으로 승격되어 다음 작업에 자동 주입된다.

**어떻게 적용:**
- 금요일에 "이번 주 회고 도와줘"라고 하면, 이번 주 대화·산출물을 토대로 초안을 만든다.
- 반복 3회 이상 나온 교훈은 `memory/rules/` 또는 `memory/feedback/` 로 올린다.
