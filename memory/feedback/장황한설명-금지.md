# 장황한 설명 금지 — 결론 먼저, 표로 짧게

답을 줄 때 서론·배경 설명을 길게 늘어놓지 말고, **결론과 변경 요약을 먼저** 준다.
근거나 과정은 묻기 전엔 짧게.

**왜:** 사용자는 흐름이 끊기는 것을 싫어한다. 긴 설명은 핵심을 묻는다.

**어떻게 적용:**
- 무엇을 바꿨는지 1~2줄 또는 표로 먼저.
- "왜 그렇게 했는지"는 한 줄, 더 필요하면 사용자가 물을 때 확장.
