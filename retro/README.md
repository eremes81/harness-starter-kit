# 회고 (retro) — 하네스가 스스로 자라는 곳

회고는 이 하네스의 **연료**입니다. 흐름은 단순합니다:

```
일간(daily/) → 주간(weekly/) → 반복되는 교훈 → memory/ 규칙으로 승격
```

## 어떻게 쓰나

- **일간** (선택): `daily/2026-07-01.md` — 오늘 한 일·막힌 점·배운 점 한 장.
- **주간** (권장): `weekly/2026-W27.md` — 금요일 오후, 한 주를 한 장으로.
  Claude 에게 "이번 주 회고 도와줘"라고 하면 이번 주 대화·산출물로 초안을 만듭니다.

## 승격 규칙

같은 교훈이 **3회 이상** 나오면, 그것은 일회성이 아니라 규칙입니다.
Claude 에게 "이 교훈을 규칙 메모리로 올려줘"라고 하면
`memory/rules/`(또는 `feedback/`)로 승격되어, 다음부터 관련 대화에서 자동으로 떠오릅니다.

이 승격이 바로 "하네스가 스스로 자라는" 순간입니다.
