# 하네스 스타터 키트 (Harness Starter Kit)

> 책 부록. **받아서 폴더째 Claude Code 로 열면 바로 도는** 최소 하네스입니다.
> 챗봇을 "그때그때 쓰는" 단계에서, **내 규칙을 기억하고 자동으로 적용하는 동료**로
> 바꾸는 가장 작은 뼈대입니다.

이 키트가 하는 일 한 줄: **내가 말을 걸 때마다, 지금 대화에 관련된 내 규칙·결정·피드백을
자동으로 찾아 Claude 에게 먼저 알려 줍니다.**

---

## 0. 필요한 것 (준비물)

| 준비물 | 이유 | 확인 방법 |
|--------|------|-----------|
| **Claude Code** (데스크톱 앱) | 이 폴더를 여는 도구 | 앱 실행 → 이 폴더 열기 |
| **Python 3** | 훅과 스크립트가 파이썬 | Claude 에게 "파이썬 설치돼 있어?"라고 물어보세요 |

> Python 이 없다면, Claude Code 에게 "파이썬 설치를 도와줘"라고 하면 안내해 줍니다.
> (Windows 는 [python.org] 설치 시 "Add to PATH" 체크가 핵심입니다.)

---

## 1. 설치 (3단계, 5분)

1. **이 폴더를 통째로** 원하는 위치에 둡니다. (예: `문서\내-하네스\`)
2. **Claude Code 데스크톱 앱**을 열고 → **이 폴더를 작업 폴더로 선택**합니다.
3. 첫 대화에서 이렇게 말합니다:
   > "이 폴더의 CLAUDE.md 를 읽고, 하네스가 동작하는지 점검해줘."

끝입니다. 이 폴더에는 `.claude/settings.json` 이 들어 있어서,
폴더를 여는 순간 **메모리 자동 주입 훅이 켜집니다.**

---

## 2. 동작 확인 (30초)

Claude 에게 이렇게 물어보세요:

> "이번 주 회고 좀 도와줄래?"

`memory/decisions/주간회고-금요일오후.md` 규칙이 자동으로 딸려 들어와,
Claude 가 "금요일 오후에 `retro/weekly/` 에 남기기로 했었죠"를 **먼저 알고** 답하면 성공입니다.

> 안 되면: Claude 에게 "매니페스트 다시 만들어줘"라고 한 뒤 다시 시도하세요.
> (내부적으로 `python scripts/build_manifest.py` 를 실행합니다.)

---

## 3. 내 것으로 만들기

### (1) CLAUDE.md 채우기
`CLAUDE.md` 의 `[[대괄호]]` 부분(이름·역할·하는 일)을 당신 것으로 바꾸세요.
Claude 에게 "CLAUDE.md 를 내 상황에 맞게 채워줘"라고 해도 됩니다.

### (2) 내 규칙을 메모리로 추가하기
반복되는 나만의 규칙이 생길 때마다 Claude 에게:
> "새 규칙 메모리 만들어줘 — 이메일 회신은 24시간 안에, 라는 규칙"

그러면 `memory/rules/` 에 새 파일이 생기고, 매니페스트가 갱신되어
다음부터 관련 대화에서 자동으로 떠오릅니다.

### (3) 예시 메모리 지우기
익숙해지면 `memory/` 의 예시 3개(보고서·회고·설명)를 지우거나 고치세요.
지운 뒤에는 "매니페스트 다시 만들어줘"만 해주면 됩니다.

---

## 4. 폴더 안내

```
harness-starter-kit/
├─ README.md               ← (이 파일)
├─ CLAUDE.md               ← 세션 시작 시 Claude 가 자동으로 읽는 가이드
├─ .claude/
│  ├─ settings.json        ← 폴더를 열면 훅을 켜는 설정
│  └─ hooks/
│     ├─ inject_memory.py  ← 관련 메모리를 자동 주입하는 훅 (핵심 엔진)
│     └─ retro_check.py    ← 세션 시작 시 회고가 밀렸으면 알림 (루프 엔지니어링)
├─ memory/                 ← 내 규칙·결정·피드백·개념
│  ├─ rules/ decisions/ feedback/ concepts/
│  └─ _jit_manifest.json   ← 훅이 읽는 색인 (자동 생성물)
├─ team_memory/            ← (선택) 팀으로 쓸 때: 공유 규칙 + 팀원별 공간
│  ├─ shared/              ← 팀 공통 규칙 (합의 후에만 수정)
│  ├─ atoms/               ← 팀 공유 메모리 (개인과 함께 자동 주입)
│  └─ <이름>/              ← 팀원별 협업 스타일·메모·회고
├─ governance/             ← (선택) 정착·확장 시: 비용 가드 + 의사결정 추적
│  ├─ cost/prices.json     ← 단가 표 (공식표에서 직접 채움)
│  └─ decisions/           ← 결정 카드 (owner·rationale·역추적)
├─ scripts/
│  ├─ build_manifest.py    ← 메모리를 스캔해 색인 재생성 (개인+팀)
│  ├─ new_memory.py        ← 새 메모리 한 장 생성
│  ├─ price_check.py       ← 호출 비용 계산 (비용 가드)
│  └─ decision_track.py    ← 결정 카드 박제·영향 역추적
└─ retro/                  ← 일간·주간 회고 (루프의 연료)
```

> **혼자면** `team_memory/` 는 무시해도 됩니다. **여럿이 쓰면** 이 층을 켜세요.
> 자세한 설명은 `team_memory/README.md`.

---

## 5. 왜 이렇게 만들었나 (원리)

- **CLAUDE.md** = 항상 필요한 최소한의 맥락(내가 누구인지)만. 자동 로드.
- **메모리 + 훅** = 나머지는 "관련될 때만" 꺼낸다. 토큰 낭비 없이, 핵심이 안 묻힌다.
- **회고 루프** = 반복되는 교훈을 규칙으로 승격 → 다음부터 자동 적용 → 하네스가 스스로 자란다.

이 세 가지가 맞물리면, 챗봇은 **매번 처음 만나는 도구**에서
**어제의 나를 기억하는 동료**로 바뀝니다.
